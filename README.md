## About This Repository

This repository contains five academic projects completed as part of my Introduction to Customer Service & Help Desk course at Valencia College.

These projects helped me develop practical skills in IT support, customer service, troubleshooting, technical research, and problem-solving.

## Projects

### Project 1 - Vendor Support Website Evaluation

In this project, I compared the customer support websites of Dell, Lenovo, and Apple.

I evaluated how easy it was to find information, understand technical instructions, contact support, and navigate each website.

**Skills:** Customer Support, Research, User Experience Evaluation

[View Project 1](https://github.com/bguimaraesbarrosl/valencia-help-desk-projects/blob/main/Project-01-Vendor-Support-Website-Evaluation.docx.pdf)

---

### Project 2 - OEM vs. Refilled Printer Cartridges

I created a PowerPoint presentation comparing original manufacturer (OEM) printer cartridges with refilled cartridges.

The presentation covers cost, print quality, reliability, environmental impact, and possible technical support issues.

**Skills:** Hardware Research, Technical Analysis, Problem-Solving, Presentation Skills

[View Project 2](https://github.com/bguimaraesbarrosl/valencia-help-desk-projects/blob/main/Project-02-OEM-vs-Refilled-Printer-Cartridges.pptx.pdf)

---

### Project 3 - Help Desk Ticketing and Knowledge Base

In this hands-on project, I used Jitbit Helpdesk to practice common IT support tasks.

I created a knowledge base article about Windows performance issues, submitted a support ticket, prepared a standard response, and reviewed technician activity reports.

I also compared Jitbit with LBE Helpdesk.

**Skills:** Ticket Management, Troubleshooting, Knowledge Base Documentation, Technical Support

[View Project 3](https://github.com/bguimaraesbarrosl/valencia-help-desk-projects/blob/main/Project-03-Help-Desk-Ticketing-and-Knowledge-Base.docx.pdf)

---

### Project 4 - Laptop Product Comparison Analysis

I reviewed a CNET article comparing different laptops.

I analyzed product specifications, performance, battery life, pricing, and other factors that help customers choose the right computer.

I also evaluated the comparison methods and suggested additional criteria, such as warranty and customer support.

**Skills:** Product Research, Hardware Evaluation, Critical Thinking, Customer Recommendations

[View Project 4](https://github.com/bguimaraesbarrosl/valencia-help-desk-projects/blob/main/Project-04-Laptop-Product-Comparison-Analysis.docx.pdf)

---

### Project 5 - Workstation Improvement Recommendations

In this project, I prepared a professional memo with recommendations for improving employee workstations.

I researched affordable solutions for workspace organization, comfort, cable management, static electricity, and equipment maintenance.

**Skills:** IT Support, Workplace Troubleshooting, Hardware Research, Technical Recommendations, Professional Communication

[View Project 5](https://github.com/bguimaraesbarrosl/valencia-help-desk-projects/blob/main/Project-05-Workstation-Improvement-Recommendations.pdf.pdf)
